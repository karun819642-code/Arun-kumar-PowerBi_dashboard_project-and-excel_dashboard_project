# 📱 Mobile Sales Power BI Dashboard

## 📊 Project Overview

This project is an interactive Mobile Sales Dashboard created using Microsoft Power BI.

The dashboard helps analyze mobile sales performance using different business insights and interactive filters.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

- Total Sales
- Total Quantity
- Total Transactions
- Average Sales
- Sales by City
- Sales by Mobile Model
- Monthly Sales Analysis
- Payment Method Analysis
- Customer Rating Analysis
- Day-wise Sales Analysis
- Interactive Filters

## 🎯 Key KPIs

- Total Sales: 769M
- Total Quantity: 19K
- Total Transactions: 4K
- Average Sales: 40K
